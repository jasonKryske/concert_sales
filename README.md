# concert_sales
Git folder in databricks containing an analysis of concert data from live nation.


Instruction from Live Nation:

Please do not spend more than 1 hour on this exercise. Given the 1 hour time constraint, we expect the final result to be preliminary. But we will ask questions on your thought process and decisions for the questions below.

1.	Both concerts and upsells (e.g. parking, VIP club, etc.) are considered “events” when referring to ticket sales. When searching for the events for an artist in our database, both the concert and upsells are often returned. Take the dataset events.csv for Neon Harbor’s Super Awesome Tour and write an efficient SQL query that links / associates the primary concert event with the concert’s upsells. Please add comments and include any assumptions that you made.

2.	For all the events in events.csv, take the minute time-series ticket_sales.csv data and analyze how ticket sales are going for each show. Using the events query above, find the top 2 and bottom 2 shows (including both concert and upsell sales) for the tour (using SQL, Python, or other scripting language). Explain your findings, visualize and share any insights you find.

3.	Take your findings from #1 and #2 above and provide some recommendations that could be helpful for the promoter to make Neon Harbor’s Super Awesome Tour more successful (for this tour and / or future tours). Feel free to use slides (no more than 3 slides) or any other tool you would like to use to share the recommendations.
